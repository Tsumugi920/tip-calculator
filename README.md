# 💰 小费计算器（Tip Calculator）

一个**纯静态单页应用**：无构建步骤、无后端、无任何第三方依赖，只有 4 个文件。
双击 `index.html` 即可使用，所有数据保存在浏览器本地（localStorage）。

## 功能

- **实时计算**：输入账单金额、小费比例、用餐人数，立即算出小费、总计、人均分摊，以及每人小费 / 每人账单等明细。
- **比例输入**：预设快捷按钮（0% / 10% / 15% / 18% / 20% / 25%）+ 滑块 / 数字框自定义任意比例（0–100%，支持 0.5 步进）。
- **取整方式**（四舍五入选项）：
  - 不取整
  - 总计四舍五入到元
  - 人均四舍五入到元
  - 人均向上取整（多付不少付）
- **账单记录**：可把当前输入保存为一条账单，支持一键载入回表单、删除；首次打开自动内置 **3 条示例账单**，也可随时点「恢复示例账单」。
- **数据持久化**：表单当前值与账单列表全部存于 localStorage（键 `tip-calculator:v1`），刷新或重开浏览器不丢失。
- **JSON 导入 / 导出**：一键导出全部账单为 JSON 备份文件；导入时按 id 合并去重（同 id 更新，新 id 追加），无效条目自动跳过。
- **其他**：人数步进按钮、清空输入、两步确认清空全部记录（防误删）、响应式布局（手机可用）、纯前端无任何网络请求。

## 使用方式

方式一：直接用浏览器打开 `index.html`。

方式二（本地静态服务）：

```bash
cd tip-calculator
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 计算规则

- 金额内部统一用**整数分**计算，避免浮点误差。
- 小费 = 账单 × 比例（按分四舍五入）；总计 = 账单 + 小费；人均 = 总计 ÷ 人数。
- 取整只会上调、不会让总额低于账单本身（例如小费为 0 时不会出现负数小费）。
- 人均分摊如出现半分钱，显示时按四舍五入保留两位小数。

## 数据与备份

localStorage 键名：`tip-calculator:v1`，结构：

```json
{
  "state": { "bill": "", "tipPercent": 15, "people": 2, "rounding": "none" },
  "bills": [ { "...": "见下" } ]
}
```

导出的 JSON 文件格式（导入时兼容顶层数组或 `{ "bills": [...] }` 两种形式）：

```json
{
  "app": "tip-calculator",
  "version": 1,
  "exportedAt": "2026-10-25T12:00:00.000Z",
  "bills": [
    {
      "id": "b_abc123",
      "name": "账单 10-25 12:00",
      "bill": 86.5,
      "tipPercent": 18,
      "people": 3,
      "rounding": "none",
      "createdAt": "2026-10-25T12:00:00.000Z",
      "sample": false
    }
  ]
}
```

`rounding` 取值：`none` ｜ `total-nearest` ｜ `person-nearest` ｜ `person-up`。

## 隐私

应用不发起任何网络请求，数据只存在于你的浏览器里；换设备或换浏览器请用「导出 JSON / 导入 JSON」迁移。
